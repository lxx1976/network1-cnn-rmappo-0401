# 分层注意力机制
或者说根据分层注意力机制来决定奖励策略？两套奖励策略分别在前期大面积解决大量待处理数据和后期信息比较全了之后的远距离残余任务处理  

我现在的想法是先把这个两个网络的给做了，说的分层网络其实就可以理解为对无人机的两套奖励规则，比如训练时先训练第一个网络，第一个网络用来搜索获得所有终端信息，无人机在进入终端200m的范围内算是找到这个终端，就能获得这个终端的位置（三维）和数据量（一维），无人机在搜索到终端后会获得奖励，在每个时间步会受到惩罚，这样的逻辑能够督促无人机尽快找到全部终端。在无人机找到全部终端后，保留当前无人机的位置。由于两个阶段模型一起训练会极大程度造成训练迟缓，所以只保留无人机位置，到时候再用于第二层网络的训练

网络层1：我希望把这个用于训练计算的逻辑改成一个用于训练搜索的逻辑，就是状态观测在最开始时看不到所有终端的位置和数据信息的，他们都用一个极大值来占位。然后无人机开始搜索，就是在这个场地中飞行，在进入终端位置200m以内时，相当于发现这个终端，就获得奖励，被发现过的终端就只在被发现的时候能够提供一次奖励，被发现
  后就不能再次提供奖励了。这时观测状态就有一个终端的信息变成了发现的终端的信息。就这样修改当前代码工
  程来满足我的上述要求。无人机在飞行时还是按照当前的能耗惩罚，但是计算数据将得到非常低的奖励，比如把 
  现在的处理数据奖励权重除以1000

# chatgt的创新点梳理：
1.提出一种面向未知终端环境的双阶段多 UAV 协同优化框架，将终端搜索与状态估计、协同移动与任务服务解耦，缓解大规模场景下单策略学习困难的问题。

2.设计阶段自适应奖励机制，使策略在任务前期侧重信息获取和大规模任务削减，在任务后期侧重远距离残余任务处理与总体完成效率提升。

3.构建多 UAV—多终端合作竞争机制，通过奖励信息共享、协同服务与冲突规避，抑制重复覆盖、无效竞争和资源浪费。

4.提出基于聚类的任务图谱压缩方法，对 UAV 观测到的终端位置和任务状态进行区域级聚合，降低决策维度并增强协同规划能力。
